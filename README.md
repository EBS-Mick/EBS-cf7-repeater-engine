# EBS CF7 Repeater Engine

Generic JavaScript engine for Contact Form 7 Repeaters.

## Features

- ES5 compatible
- No jQuery dependency
- Generic rule engine
- Configurable summary
- WordPress friendly

## Build

Windows

```bat
build.bat
```

Linux / macOS

```bash
./build.sh
```

The generated file is:

```
js/cf7-repeater-engine.js
```
